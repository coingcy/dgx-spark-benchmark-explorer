# DGX Spark 模型实测分析

基于公开测试报告的交互式分析网页。资料截点：**2026年11月4日**。

## 内容

- 140条测试单元，来自20项数值资料；另列5项方法、索引或搭建分享。
- 覆盖1、2、3、4、8台DGX Spark／GB10，OEM与混合集群保留注明。
- 按参与台数、模型、引擎、精度、指标口径和来源筛选；支持搜索与详情。
- 6组实验内部的扩展对照，包含吞吐和每token时延，分别保留单位。
- 每条记录保留测试条件、限制和原始链接。

这是一轮公开检索后的有选择摘录，**不是全网普查或硬件性能承诺**。数值由原作者报告，未独立复跑；不跨模型、精度、上下文或并发求平均。54个模型标签包含版本、历史lane及class命名，不等于54个基础模型。

## 部署

本项目是静态网页。`index.html`内嵌完整页面、数据与运行组件，无需后端或构建步骤，也不依赖外部CDN。GitHub Pages可从`main`分支根目录直接发布。`.nojekyll`关闭Jekyll处理。

下载`index.html`后也可直接用浏览器打开。个人筛选和界面编辑仅影响该浏览器，不会改写仓库中的研究数据。

## 文件

- `index.html`：已构建、可独立部署的完整应用。
- `src/`：页面布局、筛选与详情交互的作者源文件；使用共享Data组件接口。
- `data/reviewed-benchmarks.json`：140条摘录、25项来源和统计口径，可供核对与再分析。

页面源文件为原始创作入口，不是独立npm构建项目；部署和离线阅读请使用已构建的`index.html`。更新数据后应重新生成页面，单独更改JSON不会自动改变内嵌数据。
